# Contributing

This repository is a read-only, curated export of NVIDIA's internal DocsFab
development. It is early-access alpha.

## Report a bug or request a feature

Open a GitHub issue. Include what you expected, what happened, and the
command or configuration that reproduces it. A maintainer triages the issue
and, when it's accepted, carries the fix into internal development and links
back to the issue when it lands in a future export.

## Pull requests are not merged

Every change to this repository comes from the next curated export, which
overwrites anything committed directly here. A pull request opened against
this repository is closed with a pointer back to this file; it cannot survive
the next export, so it is never merged, even if it looks correct.

If you have a fix, open an issue describing it instead. A maintainer writes
the change from your description as part of internal development.

## No inbound code

Because pull requests aren't merged, this repository does not require a
contributor license agreement or a developer certificate of origin for the
0.0.1 alpha.

## Report a security issue

Do not open a public issue for a security vulnerability. See
[SECURITY.md](SECURITY.md).
