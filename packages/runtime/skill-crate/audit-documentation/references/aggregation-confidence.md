# Evidence Agreement and Confidence

Compare the focused document with the declared documentation set and the
requested outcomes at the frozen revision. Record what each path can establish
and whether the paths are independent. A navigation entry generated from the
same outline as the page is not independent confirmation of coverage.

Agreement strengthens an assessment only when the evidence covers the actual
coverage question, including which page in the set owns the topic. Do not turn
a count of agreeing paths into a percentage probability that the set is
complete. If the output contract requires numeric confidence, give a bounded
judgment with its evidence and limitations; it is an uncalibrated estimate,
not an observed success rate.

Do not use agreement among documentation paths to decide source-vs-claim,
example validity, or unsupported technical claims.

## Conflicting Evidence

1. Preserve each coverage question, source locator, revision, and conflict.
2. Apply the declared set inventory, navigation, and requested outcomes.
   A sibling page can assign a topic that the target never covers. Repository
   proximity or a majority vote does not decide which page owns the gap.
3. Distinguish a focused-page coverage gap, a documentation-set assignment
   defect, an undeclared scope problem, and missing required evidence. Name
   the evidence or owner decision needed.
4. Recommend only a documentation-set or scope correction supported by that
   authority. Never convert a technical-claim dispute into an audit defect.

For example, an install page that omits recovery while the troubleshooting
index sends failed-install recovery back to that page is a coverage conflict.
Inspect the declared set assignment and requested outcomes before recommending
a page addition or a navigation fix. Until then, retain the gap and
uncertainty rather than declaring either page complete.

Missing evidence stays missing. A supplied lint receipt cannot fill a gap in
set-assignment evidence, and agreement cannot average away a known hard
failure.
