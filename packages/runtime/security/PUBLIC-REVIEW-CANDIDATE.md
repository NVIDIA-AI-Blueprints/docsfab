# Public Review Candidate

The review candidate in this export uses a reserved example host and project.
It is a configuration example, not evidence that an external security or
product review has approved this export. Its status remains
`external-approval-required`. The model and document hashes match the source
candidate.

Before verifying a review, configure the candidate for the GitLab host and
project that hold the actual review. Bind the review client explicitly with
`DOCSFAB_THREAT_MODEL_REVIEW_GITLAB_HOST`. The verifier checks the host, source
revision, model and document hashes, required reviewers, and approvals. Changing
a destination does not grant approval or release authority.
