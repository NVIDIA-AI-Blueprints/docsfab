# Runtime documentation

Use these guides to get started with the CLI or understand a workflow. The
npm package includes the [runtime README](../README.md) and the
[installation reference](get-started/installation-reference.md). The full
runtime contract and workflow outcome references are available from a DocsFab
source checkout.

| If you want to… | Start here |
| --- | --- |
| Install DocsFab, configure a model, and choose a target repository | [Installation reference](get-started/installation-reference.md) |
| Change or validate the runtime | [Contributor guide](../CONTRIBUTING.md) |

For product behavior, start with the first two guides. Contributor commands,
generation steps, and package checks belong in the contributor guide.
