# DocsFab Public Tree

This is a curated export. This project is currently not accepting contributions.
Report bugs and feature requests as issues, as described in
[CONTRIBUTING.md](CONTRIBUTING.md). Pull requests are not merged.

## Build and Test

The runtime CLI lives in `packages/runtime`. Refer to its
[validation reference](packages/runtime/CONTRIBUTING.md) for the exported
package commands. Documentation quality checks run from the repository root:

```sh
make validate
make test
make smoke
```

Refer to [README.md](README.md) for package descriptions and installation.
