Use these references to distinguish DocsFab communication, site delivery, and
evidence freshness. None of these contracts grants merge, publication, or
release authority by itself. For more information, refer to [DocsFab Knowledge
and Delivery Reference](../index.md).

## Reference Topics

| Topic | Use it to | Not the same as |
| --- | --- | --- |
| [GitLab Host Mailbox in DocsFab](gitlab-host-notification.md) | Look up outbound status notes and inbound mention-submit behavior on an existing merge request. | Creating a new draft merge request or publishing a Fern site. |
| [Reviewed Candidate Proposals](documentation-delivery.md) | Look up the trusted-host request, source identity, and idempotent draft-MR proposal contract. | Fern site publication or merge authority. |
| [Documentation Convergence and Freshness in DocsFab](documentation-convergence.md) | Look up watched evidence, freshness results, and retained receipts. | Semantic conflict resolution or automatic documentation rewriting. |
