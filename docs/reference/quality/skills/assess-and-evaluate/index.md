These DocsFab skills assess a frozen target without rewriting it. They
preserve missing evidence, incompatible findings, and population
differences instead of averaging them into an unsupported pass. For more
information, refer to [Skill Behavior Contracts in DocsFab](../index.md).

## Skill Contracts

| Skill | Primary question | Result boundary |
| --- | --- | --- |
| [Audit Documentation Skill in DocsFab](audit-documentation.md) | What is in scope, supported, drifting, missing, or unassessed? | Inventory and findings; no release verdict. |
| [Test Audience Understanding Skill in DocsFab](test-audience-understanding.md) | What does a representative human or clean agent understand from the frozen documentation? | Controlled population-specific evidence; no coaching during measurement. |
| [Evaluate Document Quality Skill in DocsFab](evaluate-document-quality.md) | What does the complete layered evidence package establish? | Hard-gate-aware quality result; missing required evidence cannot be averaged away. |
