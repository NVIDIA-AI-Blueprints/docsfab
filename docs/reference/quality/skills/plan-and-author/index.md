These DocsFab skills turn approved evidence and scope into a bounded plan or
patch. They differ in mutation breadth and workflow exposure; none grants
publication or merge authority. For more information, refer to [Skill Behavior
Contracts in DocsFab](../index.md).

## Skill Contracts

| Skill | Use it to | Mutation boundary |
| --- | --- | --- |
| [Plan Documentation Skill in DocsFab](plan-documentation.md) | Resolve audience, sources, topology, validation, roles, and destinations. | Read-only. |
| [Write Documentation Skill in DocsFab](write-documentation.md) | Create or edit documentation, including a focused polish. | Approved scope and explicit write authorization. |

Use a workflow for a staged documentation job, or ask the live agent to apply
a focused edit with `write-documentation`.
