# Peer Review and Understanding Methods

| Dimension | Prefer | Useful measures | Do not overclaim |
| --- | --- | --- | --- |
| Audience fit | Representative audience review with declared prerequisites | Prerequisite mismatch rate; audience-specific success | One expert is not every audience |
| Conceptual fidelity | Compare documented relationships and invariants with the product reference model | Model mismatch count; unsupported relationship count | Terminology match does not prove model fidelity |
| Purpose and rationale | Trace why, causality, tradeoffs, and counterfactuals to intent evidence | Intent coverage; unanswered why questions | Plausible rationale is not approved intent |
| Terminology | Check definitions and use across pages and surfaces | Undefined term count; semantic contradiction count | Spelling consistency is not semantic consistency |
| Clarity | Editorial review plus comprehension evidence | Ambiguity findings; comprehension accuracy; readability diagnostic | Reading grade is not comprehension |
| Editorial style | Apply the selected style profile and independent editorial judgment | Rule violations; consistency findings; bias findings | Style conformity does not establish truth or understanding |
| Examples | Test representativeness, boundaries, and counterexamples | Concept-to-example coverage; misleading example count | More examples are not necessarily better |
| Information architecture | Tree tests, dependency review, and independently retrieved topic tests | Correct placement; dead ends; unsafe detached-topic count | Navigation depth alone is not quality |
| Visual explanation | Compare diagrams with the model and accessible text equivalent | Diagram mismatch count; text-equivalence coverage | Attractive diagrams can teach the wrong model |
| Mental-model transfer | Pre/post or controlled novel-scenario evaluation | Prediction accuracy; relationship explanation; unseen-task success; misconception rate | Recall is not transfer |

For a style finding, record the exact governing source and why it applies to
the frozen path and audience. A familiar house preference is not automatically
a repository rule. In particular, contractions require an applicable style
rule or concrete clarity evidence. Automatic Markdown numbering using repeated
`1.` markers is valid CommonMark/GFM; require a rendered defect or an applicable
contrary rule before reporting it.

Keep material state and boundary qualifiers verbatim when consolidating
findings. `A nonempty response header updates the token` is not equivalent to
`a response header updates the token`: the latter silently changes empty-header
behavior.

When supplied audience evidence is in scope, check its frozen oracle,
participant independence, item-level results, and sample size. Preserve missing
or contaminated evidence. This editorial review does not create transfer items,
recruit participants, run an experiment, or turn expert prediction into observed
understanding; the separately authorized audience protocol owns that work.
