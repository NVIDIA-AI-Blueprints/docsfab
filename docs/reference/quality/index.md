Use this section to identify the DocsFab quality question, evidence type, and
skill contract you need. For the quality mental model and assurance lifecycle,
start with [Documentation Quality in
DocsFab](../../about/core-concepts/documentation-quality.md). For more
information, refer to [Overview of DocsFab](../../about/index.md).

## Reference Topics

The following table maps each quality question to its reference topic.

| Question | Topic | Result |
| --- | --- | --- |
| Which hard constraint applies, and is sufficient evidence retained? | [Documentation Constraint Evidence in DocsFab](documentation-constraint-evidence.md) | Applicability, current result, evidence, owner, and next evidence. |
| Which function must be performed, by whom, and with what independence? | [Quality Roles and Capability Coverage in DocsFab](quality-roles-and-capabilities.md) | Required outcomes, capability slots, provider rules, and implementation boundary. |
| What does one reusable documentation skill consume, produce, and forbid? | [Skill Behavior Contracts in DocsFab](skills/index.md) | Eight canonical behavior contracts grouped by workflow stage. |

Deterministic checks, technical verification, editorial review, audience
evidence, and quality evaluation answer different questions. A pass in one
layer does not substitute for required evidence in another.
