These DocsFab skills collect different evidence from frozen source and the
same frozen artifact. An inventory-only `verify-technical-accuracy` ledger
does not replace a passing deterministic check, canonical technical
verification, or independent review. For more information, refer to [Skill
Behavior Contracts in DocsFab](../index.md).

## Skill Contracts

| Skill | Primary question | Evidence |
| --- | --- | --- |
| [Lint Documentation Skill in DocsFab](lint-documentation.md) | Did the artifact satisfy selected deterministic or policy-based checks? | Exact commands, statuses, relevant output, and untested scope. |
| [Verify Technical Accuracy Skill in DocsFab](verify-technical-accuracy.md) | What source facts must documentation account for, and do consequential claims agree with authoritative evidence or observed behavior? | Inventory-only ledger proposal; later claim inventory, observations, findings, and unverified remainder. |
| [Review Documentation Skill in DocsFab](review-documentation.md) | Does the frozen artifact serve its audience with clear, coherent, usable content? | Independent, located, actionable editorial and usability findings. |
